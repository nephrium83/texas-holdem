# Poker TDA 2024 authoritative source

This directory contains a reviewable UTF-8 extraction of the official Poker
Tournament Directors Association 2024 Rules, Version 1.0, dated October 9,
2024. It includes the rules, recommended procedures, and illustration
addendum.

The text file is a mechanical extraction from the official DOCX. Paragraphs
and table cells remain in document order. It is provided so offline coding and
review agents can cite exact numbered TDA rules without treating repository
interpretation as authority. When exact layout matters, verify against the
official PDF identified above.
